# Contributing to WebAtlas 🕸️

Thank you for considering contributing to WebAtlas!

### How Can I Contribute?

#### 🐛 Reporting Bugs
* Check the **Issues** tab to see if the bug has already been reported.
* If not, open a new issue. Please include:
    * Your Screaming Frog version.
    * A screenshot of the error (if possible).
    * A brief description of what you were doing when the "mothball" broke.

#### ✨ Suggesting Enhancements
We are always looking for ways to make the graph more insightful! Current ideas include:
* Coloring nodes by Status Code (200 = Green, 404 = Red).
* Sizing nodes based on "Link Score" or Internal PageRank.
* Adding a "Silo" view to separate folders.

#### 🛠️ Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests!
3. Ensure the documentation (README) is updated if you change how the script runs.
4. Issue that Pull Request!

### 🔒 Data Privacy
When contributing examples or bug reports, **please redact any sensitive client URLs** or internal data. We recommend using `example.com` for all test data.

### ⚖️ Code of Conduct
Be kind, be professional, and let's build something cool together.
